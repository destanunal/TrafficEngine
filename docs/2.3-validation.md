## Simplified blueprint interface

- One plan; the previously active slot is migrated. The second corner automatically captures the current plan. Shift + right-click clears that selection and plan while preserving repetition settings. Preview, rotation and repetitions share one main page. Materials opens from the upper-right button.
- Native Fabric, Forge and NeoForge break-cancellation hooks guard undo. Undo verifies block state and block-entity data, suppresses teardown drops/particles, and refunds exact consumed stacks once per removed copy. The queue shares the one-copy-per-tick construction budget; history has player, lifetime and estimated byte limits.
- Both common modules and all four loader modules passed compileJava. BlueprintCheck passed 153,068 assertions per version, including migration, reset preservation, changed-data protection, cache eviction, byte budgets and server cleanup. Actual UI appearance and multiplayer undo/protection integration still require live-game testing; no FPS or heap claim is made.

## Automatic capture and true empty-block spacing

- Removed manual save, delete and naming controls, plus the obsolete network commands and localization strings. The second matching corner captures the plan on the server and enters placement mode. A fresh selection cannot accidentally reuse an old plan. Reset retains repeat settings and undo history.
- The slider is a gap between occupied block-cell footprints. Repeat step equals rotated occupied width plus the requested gap; leading/trailing air in the selection does not inflate it. One-block structures at Gap 4 are five blocks apart, leaving four empty cells. Client preview and server jobs call the same bounded helper once per layout/job.
- Added corner/reset regressions and 4,096 gap cases across widths, depths, four rotations, four directions and gaps 1/4/8/32, plus an explicit preview regression for Gap 4. Live gameplay/visual testing is not covered by the headless checks.

## Directional sign panel borders

- Replaced camera-dependent stroke widening/color approximation with a shared 512x256 atlas containing the original panel fills, 0.6-unit strokes and two-tone outer frames. Fixed nine-patch coordinates preserve physical dimensions. Up to nine quads replace the subdivided border/fill rings on placed directional signs; the editor and variable-speed display retain their existing drawing paths.
- Four mip levels and bilinear/trilinear sampling resolve subpixel lines. Alpha-weighted downsampling preserves coverage; visible RGB is extruded into transparent gutters separately at each mip. Every tile, including the white sample used by arrows, has transparent edge padding to prevent atlas cross-contamination. Joining signs sample the interior at shared sides rather than introducing a vertical frame.
- The dedicated texture is generated on initial load/resource reload. All mip levels total 698,368 GPU bytes, shared regardless of sign count; temporary CPU pixels/native images are released after upload. Geometry has no camera-distance rebuilds, projection queries or per-frame mesh arrays. Arrow/detail batches sample the same atlas. Global texture filtering, mip settings and other block atlases are untouched.
- Reduced artwork/casing clearance from 1/32 to 1/1024 block to avoid a detached second silhouette, retaining the existing depth bias. Picking/collision, panel dimensions, text positions and sign settings are unchanged.
- Validation: common compileJava, generated-pixel/mip/patch/cache regressions and a hidden native OpenGL harness rendering the production atlas at five scales and ten subpixel phases. The harness checks 4,670 edge samples for breaks and unstable coverage and writes an image for inspection. If Minecraft 1.20.1's cached LWJGL lacks native binaries, this standalone harness uses a matching installed LWJGL runtime; game dependencies are unchanged. These checks do not exercise an actual Forge/Fabric/NeoForge world, shader pack, fog or FPS/heap usage.

## Ceiling fluorescent lamps and catalogue scrollbar

- Fluorescent tube lamps beneath a sturdy ceiling underside automatically use a flush baked model, shifted 6.7 model pixels upward. The ceiling variant omits its hidden top face and pole connectors; normal pole models remain the default for old states. Direction, waterlogging, dye and scheduled/manual lighting keep their existing paths. Ceiling removal restores ordinary connectors.
- Matching ceiling picking/collision uses one cached box per direction. All 128 ordinary direction/connector combinations are precomputed once; shape queries allocate no geometry and read no world blocks. Mounting checks only placement and upper-neighbor changes, with no added ticker or renderer.
- Sign pattern catalogues show an accent-colored scrollbar whenever more rows exist, for both creative and stored patterns. Supports wheel, track clicks and thumb dragging without jumping on thumb grab. Unchanged/boundary scroll events do not rebuild cells or reload textures. Scrollbar geometry is bounded integer arithmetic; preview heading uses the reload-aware centered text helper.
- Validation: affected common compileJava tasks, targeted lamp support/geometry regressions and JSON model/state coverage checks on both Minecraft branches. Live client visuals, dragging and shader/FPS measurements are not covered by headless checks.
