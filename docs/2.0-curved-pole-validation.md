# Traffic Engine 2.0 — curved mast and item/lens follow-up

Validated on 2026-10-26 for Minecraft 1.20.1 and 1.21.1.

## Implemented

- `curved_traffic_pole`: a galvanized upper mast arm placed on an existing pole. It rises 1.5 blocks and reaches 3 blocks outward, with a downward terminal mounting stub for a traffic signal. Four horizontal placement directions; structure rotation/mirroring preserves the six-cell footprint. One inventory entry, one item consumed/dropped per complete assembly. EN/TR/DE names, recipe, loot and pickaxe tag included.
- Placement preflights the six explicit cells for loaded chunks, world/build border, replacement, block entities, permissions and entity collision. Rejected writes roll back the cells already changed. Removal touches matching, loaded parts only; neighbours perform a coalesced one-shot integrity check. No chunk is loaded solely for validation/removal. Pieces on unloaded chunk edges revalidate upon subsequent neighbour updates.
- Mast rendering uses ordinary baked chunk models. There is no block entity, custom renderer, recurring timer, network channel or world scan. Twenty-four immutable outline shapes cover all six parts/four directions, shared by water states. Bezier geometry is sampled offline from controls (8,0,8), (8,24,8), (8,24,-24), (8,24,-40), with 64 segments and a two-model-unit tube.
- Gate and sloped-railing item hand scales now match the existing flat railing. Both inventory views use its GUI transform. The sloped item has centered, normalized geometry and a more apparent slope; its world grades are unchanged. Contrasting hinges and a projecting latch distinguish the gate.
- The new single-sided vertical signal model has circular lenses, an octagonal bezel and a 0.19-model-unit white front reveal. One through four lights, diagonal variants, inventory and configuration previews are covered. Previously preserved double-sided body resources remain untouched.
- Circular lens alpha is derived from the existing textures only on load/reload, using a finite enum-indexed alias table. No PNG or audio asset was added. Rounded world lenses submit only their front surface instead of the old four-sided light slab. Separate symbol backgrounds retain ordinary world lighting; the glyph remains emissive. Custom drawings and countdown values remain editable.

## Validation

- Both versions: `:common:compileJava` passed. Existing mixin/deprecation warnings only. No packaging/build/JAR tasks were run.
- Native `CurvedPoleCheck`: 957 assertions per version, including all 48 states, cached shape identity, local shape bounds, owner coordinate round-trips at chunk edges, mounting ports, water state reuse, structure rotations, unique/connected footprint and Minecraft's actual JSON model deserializer.
- Asset/data follow-up: 10,734 checks across both versions, including native model coordinates/UVs/angles, localization, item transforms/centering and master-only loot.
- 48,000 isolated warm shape lookups: 4.74 ms (1.20.1), 5.28 ms (1.21.1), zero world reads. Cold isolated class/construction measurements: 163.0 / 138.7 ms. These are microchecks, not FPS benchmarks.
- `git diff --check` passed for both workspaces.
