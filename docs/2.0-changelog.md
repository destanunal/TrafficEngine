# **🆕 Traffic Engine Update 2.0**

This update introduces new roadside equipment, independent double-sided traffic lights, expanded signal customization, improved drawing tools and redesigned traffic light models.

---

## **🚦 Traffic Lights & Control**

- Traffic lights now feature a modern design with circular lenses, slim white borders, and realistic housings and sunshades.
- Double-Sided Traffic Lights have been added, with independent settings and controller connections for each face.
- Individual lamps can now use different symbols or custom drawings.
- Selecting None for the controller transition now skips yellow only between red and green. The cycle remains Red → Green → Yellow → Red.

---

## **🚧 Roadside Equipment**

- Hydraulic Bollards have been added, with retractable bodies controlled by a wrench or Redstone.
- Curved Traffic Poles have been added, featuring a smooth mast arm and a downward mounting point for traffic lights.
- Horizontal traffic lights can be mounted beneath curved poles.
- Curve Direction Signs now support diagonal placement.
- Pole bases can now be embedded in supported road, curb, and sidewalk slopes.
- Pole bases now include a short pole and a more compact footing.

---

## **🚶 Pedestrian Equipment**

- Pedestrian Railings have been added, with automatic straight, corner, end, and vertical connections.
- Railings default to gray and can be switched to charcoal using a wrench.
- Sloped Pedestrian Railings have been added for ramps and changes in terrain height, with automatic terrain adjustment and manual slope selection.
- Pedestrian Railing Gates have been added, matching the railing design and supporting manual operation and Redstone control.
- The pedestrian request button has been redesigned with a modern yellow housing and localized WAIT / WALK panels in English, Turkish, and German.

---

## **🎨 Drawing Tools & Custom Patterns**

- Custom road patterns can now be saved to favorites and selected again later.
- Adjustable pencil and eraser sizes have been added to the road pattern, traffic light symbol, LED, and sign editors.
- Tool sizes can be changed using the mouse wheel or size controls.
- Compact pencil and eraser icons replace text controls in the road pattern, traffic light symbol, and LED editors.

---

## **🛠️ Interface & Inventory**

- Horizontal and vertical text alignment has been improved across menus, including accented characters and translated labels.
- Traffic light symbol selection now uses the same symbol shapes as the actual lamps.
- Individual lamp drawings can be edited using pencil buttons beside the live preview.
- Traffic light previews now use the actual body model and selected body color.
- Menu layouts, button sizing, and equipment inventory presentation have been refined.

---

## **🐛 Fixes, Compatibility & Optimizations**

- Fixed an unsafe road-mesh refresh during chunk replacement that could trigger ConcurrentModificationException.
- Fixed the emissive interface mixin compatibility error affecting Forge 1.20.1.
- Improved legacy world-data loading and handling of invalid block entities.
- Improved traffic light color rendering and compatibility handling for LambDynamicLights and Sodium/Embeddium Dynamic Lights.
- Reduced redundant model data, repeated countdown calculations, and unnecessary lighting updates.
- Added bounded caches to limit memory growth during extended sessions.
