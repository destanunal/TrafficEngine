# Traffic Engine 2.0 — fitted trim, mounts, dual signals and continuous mast

Applied to Minecraft 1.20.1 and 1.21.1 source trees.

## Final changes

- Closed the single-sided lamp's thin white border with four fitted beveled corners. All one-to-four-bulb bodies, diagonals and previews use the same corrected outline. Corner depth separation prevents coplanar trim overlap.
- Replaced floating mounting pads with stems and square collars. In diagonal variants, the housing/stems turn while the collars retain the real post's square alignment. Collar heights follow housing height.
- Updated the existing double-sided traffic light to the modern round-lens housing on both faces, including diagonal/item assets. Each face selects its own body count; a single shared post avoids duplicate central geometry. Front/rear controller IDs, schedules and custom symbols remain independently stored by the existing DoubleTrafficLightBlockEntity; its data code was unchanged.
- Raised sloped railing lower rails by the half-step clearance required by their actual rise/fall and shortened their pickets accordingly. Upper handrails, post feet and inventory geometry retain their positions. The signed-grade shape cache uses the same clearance rule.
- Replaced 64 axis-aligned stair boxes in the curved mast with 28 short oriented segments following its Bezier centreline plus the terminal mounting stub. The six existing occupied/selection cells and block IDs remain compatible. One edge helper cell is crossed by its neighboring segment and therefore contains no duplicated mesh of its own.
- A narrowly marked JSON rotation hook permits finite, unscaled segment angles up to 90 degrees. The vanilla model bakery turns these into ordinary quads during resource loading. There is no new block-entity renderer, per-frame curve calculation or tick loop. The same item geometry is curved.
- Curved mast destruction uses one small cached shape rather than traversing every collision box. Default destruction constructs eight debris particles and retains four per event. Breaking a non-root assembly part can also trigger a root removal event; cleanup of the other parts remains particle-free.

## Performance and verification

- Both common compileJava tasks passed; no packaging task/JAR was requested or run.
- Per version: 4,472 native model, rotation, step-clearance and particle assertions. Minecraft deserializers were used for ordinary model fields; the new marked angle path was exercised through its actual delegate, then every authored curve vertex was rotated through vanilla FaceBakery. The exact private getAngle target exists in both versions; Mixin annotation processing compiled it successfully. This is not a full running-client Mixin integration test.
- Per version: 24,603 gate/railing/terrain assertions, covering all 4,608 railing states and 864 shared outlines. Repeated shape lookups read no terrain.
- Per version: 910 mast/shape/placement-footprint assertions, 48 states and 24 shared shapes. 48,000 repeated lookups read no world state.
- Combined: 20,445 asset checks covering connected trim, all front/rear body-count combinations, all cardinal/diagonal variants, square-collar alignment, step clearance, model bounds and rotations.
- Actual old block-model face count: 458; updated count: 120. The earlier 504 figure counted unpruned source geometry, not the previously authored in-game block files. These counts describe geometry, not FPS.
- A static depth-tested rendering of the model files was inspected for front corners, diagonal rear mounts, the double-sided item, mast curvature and step clearance. No game-window or modpack/FPS playtest was performed.

## Testing in game

Restart the development client before testing, because the smooth model loader adds a client Mixin; a resource reload alone cannot install a new Mixin in an already running session. Test cardinal and diagonal mounts, independent front/rear controllers and body counts, ascending/descending steps, and destruction from root/other mast parts. World saves and installed modpack JARs were not changed by this source-only work.
