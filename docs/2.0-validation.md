```powershell
./gradlew.bat :common:compileJava :fabric:compileJava :forge:compileJava -x :common:jar --no-daemon --max-workers=2 --console=plain -I docs/checks/compile191.init.gradle
```

## Targeted regressions

`docs/checks/Update20RegressionCheck.java` runs against the compiled common classes and the mapped Minecraft runtime classpath. It passed 126,457 assertions covering:

- Every incoming transition setting across one to four directions, automatic/manual timing, repeated cycle boundaries, retained outgoing yellow, no conflicting greens and safe crossings.
- A requested crossing with `None`; legacy NBT and zero-duration wire data; current NBT, wire and copy roundtrips.
- Independent immutable per-bulb native/custom symbols, inheritance, malformed slot bounds and packet roundtrips.
- Independent front/back phase IDs, schedules and symbols; the registered block entity factory used by chunk loading; removal/revival; distinct controller-link identities and countdown keys.
- Bounded shape identity reuse for both faces, cardinal/diagonal face picking, retained curve-sign brightness of 7, empty curve-sign occlusion geometry, gray railing defaults and all eight embedded footing depths.
- Glyph-bound vertical placement for English, Turkish, German and non-Latin fixtures at several scales; cached width/glyph lookups; font-set replacement/reload invalidation; a 1,024-entry measurement cap.

The headless check supplies four loader-only enum *icon* references from vanilla registries. Schedule logic, NBT, block states, shapes, glyph metric code and packet code are the actual production classes. It does not boot a loader or an OpenGL game window.

`docs/checks/Native20Check.java`, together with `Bulb191Check.java` and `LightVolume191Check.java`, passed native vertex-buffer checks for red/yellow/green/off lenses, different per-bulb custom-mask coordinates and colors, the 256-texture-cache fallback, finite RGB propagation (4,089 cells / 4,088 world reads at maximum strength), immutable publication, overlapping-light removal and dynamic-brightness preservation. No GL texture upload is exercised by the headless fallback check.

## Resource review

- All 64 front/back model selectors resolve to static geometry; the rear meshes omit the duplicated central support.
- The double-light inventory model contains two housings and one pole. Its item follows the normal traffic light; hydraulic bollards follow the road barrier fence.
- Railing meshes stop at Y=16; charcoal is a small shared texture. Embedded footing meshes and cached shape depths agree.
- New control labels exist in English, Turkish and German. Nearest-neighbor inspection of the actual request-button textures confirmed consistent word height and a visible gap beside the pedestrian symbol; the hand uses a compact 16×16 cutout.
- Native mapped bytecode contains the exact world-update, glyph accessor and font-reload targets used by the new client-only mixins.

## Practical limits

These are compilation and targeted regression results, not an FPS measurement or a full loader/modpack playtest. The diagonal-sign change avoids detailed occlusion-shape projection and avoids RGB invalidation for non-occluding placements, while keeping the existing brightness. The reported 130-mod OOM still requires the complete modpack/reproduction to confirm; the supplied traces alone do not establish its cause. Actual LambDynamicLights / Sodium-Embeddium Dynamic Lights combinations need in-game validation. The full Advanced controller was intentionally deferred as requested.
